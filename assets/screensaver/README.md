# ICAIF conference display assets

- `icaif-mark-white.svg`: official white master exported from the ICAIF Figma file `gVxYd7064IxKLVYlDIaeDW`, component `87:12` (white), current master `43:98`. Downloaded on 12 November 2026. Geometry and original proportions are preserved; rendered as a normal responsive image.
- `brand-waves-navy.webp`: the existing navy wave raster from the same file, node `89:6`, supplied in the “05 · Onde e risorse” page. Original 1254 × 1254 PNG, encoded as WebP at quality 88 (approximately 247 KB). Used when JavaScript or WebGL is unavailable. Its provenance sidecar records the source; the original generation prompt was not available.

The animation in `js/screensaver.js` is a new generative WebGL interpretation of the wave resource. No Figma temporary asset URLs are used at runtime. Sponsor marks reuse the unmodified local artwork and current tiers from `sponsors-and-supporters.html` (four Platinum, two Gold, two Silver, three Bronze and Needlestack À la carte).

`icaif-orbit-white.svg` contains the exact orbit path and viewBox extracted from the official master. Its geometry is used as a mask for the recurring orange light; the underlying logo remains static.
