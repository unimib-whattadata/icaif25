# SEO improvements — October 17, 2026

The user requested SEO improvements after publication of the Student Volunteer call. This change covers all 20 canonical pages and their generated clean-URL copies. Visible body content, navigation, event facts and application destinations are unchanged.

## Changes

- Search titles use the full ICAIF 2026 year. Key pages describe the visitor’s task: registration fees, deadlines, programme, AI in Finance workshops/tutorials/competitions, and Bocconi venue/travel information.
- Descriptions reflect actual content and current status. The student volunteer call retains the October 21, 17:00 CEST deadline and explicitly states that the application form link is coming soon. Registration retains the early bird deadline; the programme remains preliminary.
- HTML titles/descriptions, Open Graph, Twitter and WebPage JSON-LD stay synchronized by the SEO builder. The WebSite name is ICAIF 2026 with ICAIF '26 as an alternate name. Existing canonical routes, breadcrumbs, image attribution and conference identity are retained.
- News has a connected ItemList generated from the visible announcement titles and anchors, in the same reverse chronological order. This is descriptive metadata, not a claim to eligibility for a Google news or carousel enhancement.
- Default builds preserve each page’s existing modification date. Explicit updates can target one or several pages with `--updated YYYY-MM-DD --page news.html`. Sitemap entries use the matching page date. Invalid dates, unknown pages and missing dates fail before any generated file is written.

## Verification

`npm run build` passed JavaScript syntax checks, 36 tests, HTML validation of 39 physical files, programme/tutorial source parity, clean-URL parity and the 20-page site checker. Four SEO tests cover date preservation and repeatable output, targeted date/sitemap updates, invalid-input failures without partial writes, and News list parity. Comparing every canonical HTML body with the previous commit confirmed that visible content and navigation did not change.

No external indexing, Search Console submission, rich-result validation or ranking improvement is claimed. This task changes local source; it does not verify a deployment.
